How it works

Four moves, one front page

Bet

1,000 free paper credits on sign-up. Stake-first trading: pick an outcome, set your stake, see exactly what you get before you commit.

Watch the odds

Every bet moves the price — the odds are the crowd's live forecast, streamed over WebSocket as they shift.

Climb the board

Settled markets pay winners; the leaderboard ranks predictors. Rivals are pseudonymous — a rival, not a dossier.

Ask a question

Anyone can create a market. Creators escrow the market maker's worst-case loss, so junk questions cost their author.

Why it's fair

Settlement is a state machine, not a trust fall

The interesting part of any prediction market is what happens when a question resolves — and who could cheat. scry's engine treats a unilateral oracle as the attack it is:

  • Oracles can't trade their own markets — and their settlement claim is capped at their own escrow, so resolving dishonestly wins them nothing.
  • Any holder can lodge a bonded dispute, parking the market for an operator: uphold, re-resolve, or void.
  • Abandoned markets auto-void at a time-weighted average price — funds are never stuck, and a last-second price pump is a pure loss.
  • Conservation is asserted after every settlement: credits in the system equal credits granted, exactly. The books cannot drift.

Run it

One host file over a battle-tested engine

# a scry of your own
git clone https://github.com/melvincarvalho/scry
cd scry && npm install
node server.js          # → http://localhost:3490
node tools/seed.js      # a front page of news questions

The engine has its own home

The LMSR market maker, journalled ledger, settlement state machine and trading UI are vendored verbatim from jss-plugins/markets, where they carry a 75-test suite — and run unchanged as a JavaScript Solid Server plugin. One engine, two hosts.
